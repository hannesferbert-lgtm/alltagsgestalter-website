# Bilder hochladen

`index.html` erwartet 14 Bilddateien in diesem `assets/`-Ordner. Sie fehlen noch,
weil Binärdateien nicht über die Schnittstelle übertragen werden konnten, mit der
`index.html`, `style.css` und `app.js` eingespielt wurden.

## So fügst du sie hinzu (ca. 30 Sekunden)

1. Die 14 `.webp`-Dateien liegen im ZIP, das dir Claude im Chat geschickt hat
   (`alltagsgestalter-assets.zip`) – entpacken.
2. Auf GitHub diesen Ordner öffnen:
   <https://github.com/hannesferbert-lgtm/alltagsgestalter-website/tree/main/assets>
3. **Add file → Upload files** klicken, alle 14 `.webp` per Drag & Drop hineinziehen.
4. **Commit changes**.
